## 一、定位：不换皮，提规整

鱼庙原有的气质不能丢：**纸色底 + 墨黑 + 信号黄 + 等宽标签 + 方角 + 硬阴影**。这套和终末地同源
（浅底黑字、单一亮色、宽体英文标签、切角、极淡纹理），所以这次是**补规矩**，不是换风格。

明确不做 ✗：
- 不引入游戏素材、不做满屏科幻 HUD、不加第二第三种亮色
- 不把信号黄换成仓库默认的 `#FFFA00`（保留鱼庙的 `#FFD400`）
- 不把每个面板都切成斜角；切角只给“能按的东西”，展示用的封面 / 图片 / 面板保持直角

## 二、六维取值（我们的固定选择）

| 维度 | 我们的取值 | 说明 |
|---|---|---|
| 亮色（accent） | **信号黄 `#FFD400`** | 站点身份，不动 |
| 纸色（paper） | **`#EFEDE6`**（暖） | 现有纸色，不动 |
| 切角（cut） | **标准**：小控件 5px、常规 7px、主按钮 9px | 统一右下角 |
| 底纹（ground） | **现有网格 + 极淡等高线** | 只做背景，不铺满 |
| 疏密（density） | **标准** | 不为了“像”而牺牲可读性 |
| 动画（motion） | **满**，但尊重 `prefers-reduced-motion` | 见下 |

## 三、部件规则（全站）

- **按钮**：切右下角。默认浅灰底；主按钮 `btn--signal` 桌面墨底、悬停黄擦入，触屏静止就是黄底。
  `:active` 下压 1px，不弹跳。
- **筛选块**：切角；选中黄块，同一排只允许一个黄色“当前项”（文章页第二组筛选用墨块区分）。
- **标签**：不切角（不可点）；`tag--alert` 用黄块，红色只留给删除按钮。
- **卡片 / 看板**：不切角；顶部一段 4–5px 墨色页签，悬停沿边伸开；图片保持直角。
- **列表 / 表格行**：悬停左缘落下 `--trace` 色条（浅色=墨、深色=黄），整行右移 2–6px。
- **标题**：英文页名用宽体 Saira；中文内容标题仍用系统黑体，不做字宽拉伸。
- **编号 / 日期 / 计数**：真实数据，等宽数字；`viewhead__idx` 前面加 `//`。
- **背景**：网格与等高线只做质感，不加点阵、发光、扫描线滤镜。
- **动效**：出现用 snap，擦入 / 快门用 mech；每个入场 ≤ 1 秒，减少动效时全部静止。

## 四、落点

| 文件 | 职责 |
|---|---|
| `styles/ef.css` | 全站 UI 层（按钮 / 筛选 / 卡片 / 行 / 面板 / 输入 / 浮层 / 页面级微调） |
| `styles/tokens.css` | 切角、trace、命令栏、动效曲线等 token |
| `styles/base.css` | Saira `@font-face` |

| `styles/mobile.css` | 触控 / 窄屏适配 |

## 五、页面级“随机应变”

- **首页**：展示页，大字标与统计数字优先；统计格加顶部墨页签，按钮切角，不把首屏做成卡片网格。
- **文章 / 公告**：阅读页，卡片当“看板”（顶部墨页签 + 左 trace），两组筛选用黄 / 墨区分当前项。
- **论坛**：空态是一块完整面板，不用虚线框；搜索与按钮保持小尺码。
- **插画 / 相册**：图片永远直角、无圆角；只有按钮和筛选切角。
- **文娱**：页签是分段选择，当前段墨底反白；筛选 chip 跟随全站规则。
- **工具台 / 游戏**：工具页签、难度按钮切角；当前段墨底反白。
- **控制台 / 仪表盘**：看板顶部墨页签；图表只用黄 + 灰阶，不用红绿；表单白底细线、聚焦 trace。
- **音乐台 / 沉浸舞台**：密集控制台，深色命令栏 + 24 格进度 + 全屏歌词；详见 README。
