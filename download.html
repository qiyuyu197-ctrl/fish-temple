Android / 安装

  1. 下载 .apk 到手机（微信 / QQ 传过去也可以）。
  2. 点开文件，允许「安装未知来源应用」。
  3. 覆盖安装 2.4.2 即可；首次打开如果站点账号掉了，重新登录一次，之后杀后台不会再掉。

需要 Android 7.0（API 24）及以上；安装包约 291 MB，相册图都打进去了。

Windows / 使用

  1. 下载 .zip，解压到任意目录（别放 C:\Program Files）。
  2. 双击 FishTemple.exe；首次启动会自动在桌面创建「FISH 鱼の灵庙」快捷方式。
  3. 如果还开着旧版（1.2.0 / 1.3.0），先 文件 → 退出，再运行新版。

绿色版不写注册表；卸载 = 删掉解压目录 + %APPDATA%\FishTemple。
