## 一句话

鱼灵庙现在是一个可以慢慢逛的个人站点：文章、公告、论坛、音乐、相册、番剧档案、小游戏和工具都在同一套界面里。页面运行时零依赖，发布时只把源码打成一个单文件包。

## 十个入口

| 入口 | 路由 | 现在能做什么 |
| --- | --- | --- |
| HOME | `#/` | 首屏：正在播放、最新文章与公告、相册横幅、模块索引 |
| LOGS | `#/logs` | 文章与公告合并成一条时间线，类型 / 分类 / 标签 / 关键词都能筛 |
| FORUM | `#/forum` | 登录后发帖；帖子下面有评论、楼中楼和单张图片评论 |
| MUSIC | `#/music` | 搜索 / 导入网易云曲目，站内直放、跟唱歌词，可绑定自己的网易云账号 |
| GALLERY | `#/gallery` | 1090 张相册照片、随机插画、灯箱与收藏 |
| LEISURE | `#/leisure` | 2026 秋 22 部新番、放送表、追番标记与 Bangumi 搜索 |
| GAME | `#/mine` | 单人扫雷、联机扫雷、像素小鱼，以及两个排行榜 |
| TOOLS | `#/tools` | 格式转换、图片压缩、文本工具、Tier List、提取音频、AI 分轨 |
| CONSOLE | `#/admin` | 站长发布与修改文章 / 公告，管理内容 |
| STATUS | `#/dashboard` | 内容分布、运行状态与最近活动 |

下载页（`#/download`）单独放着 Android 与 Windows 安装包。

## 现在有多少东西

- **1090 张相册照片**：768 张旧档 + 322 张手机导入，合计约 215 MB
- **22 部当季新番**：2026 秋，按放送日排好
- **7 篇文章 / 4 条公告**：技术、设计、日志都有
- **5 套主题**：PAPER / NIGHT / BLUEPRINT / MATCHA / SAKURA
- **6 个插画数据源**：相册、站内画廊、两个公开 API、Pixiv、Pixiv 深链
- **3 种游戏模式**：单人扫雷、联机扫雷、像素小鱼

## 最近半年长出来的东西

- **论坛与评论**：注册后能发帖；帖子下面能评论、回复（楼中楼）、配一张图
- **排行榜**：扫雷按通关时间、像素小鱼按积分，一局结束就能上传
- **GAME 合并**：扫雷从单独板块并进 GAME，又加了联机房间和像素小鱼
- **相册从 768 张长到 1090 张**：手机里的插画整批导入，截图会被筛掉
- **网易云登录**：扫码绑定自己的账号后可读歌单、云盘、每日推荐；会员曲目可以自愿走登录态播放
- **工具台扩成六件**：Tier List、视频提取音频、AI 分人声 / 伴奏、docx / pptx → PDF
- **下载与离线**：PWA、Android APK、Windows 桌面版，局域网联机用站里同一套接口

## 三条边界

1. **不搬运无权限的音频**：匿名态只转发官方本来就给匿名访客的流；会员曲目要用户自己登录并显式打开开关，失败就回退官方播放器。
2. **不假装成功**：模型、接口、权限、代理任何一环拿不到，页面会说明原因，不拿假数据填版面。
3. **不上传工具文件**：转换、压缩、分轨都在浏览器里完成，关掉页面就结束。

## 怎么逛

第一次来可以先看「文章与公告」，再去「插画」翻相册；想听歌就进「音乐」，想玩一局就进「GAME」。论坛和工具台都在顶栏，命令面板（`Ctrl + K`）能直接跳。
