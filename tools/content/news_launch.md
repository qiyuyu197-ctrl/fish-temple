鱼灵庙信息终端正式启用：一个零依赖的静态站点，源码就是浏览器直接运行的那份文件。

- **八个板块**：首页 / 文章与公告 / 音乐 / 插画 / 扫雷 / 工具台 / 发布 / 仪表盘
- **音乐台**：搜索与导入网易云曲目，官方外链播放器试听，站内跟唱歌词（切板块不断播）
- **插画**：本地相册（770 张）与 Pixiv 随机插画双数据源，带磁盘缓存与去重池
- **工具台**：格式转换（docx↔txt、png↔jpg、mp3→m4a）、图片压缩、文本工具，文件不出浏览器
- **三套主题**：奶油纸 / 暗色终端 / 蓝图冷色
- **178 项自检**：用真实浏览器驱动的自动化检查，改完代码跑一遍再发布

启动方式：

```bash
node server.mjs 5173
# http://localhost:5173
```

也可以直接静态托管：没有服务器时内容读取与发布控制台会降级（存浏览器本地并可导出）。
