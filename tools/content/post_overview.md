## 这里是什么

鱼灵庙信息终端：一个**零依赖的静态站点**。没有构建步骤、没有 npm 依赖、没有 CDN，源码就是浏览器直接运行的那份文件。

界面语言借鉴工业编辑风——奶油纸底、墨黑文字、信号黄强调、全直角，三套主题共用一套 CSS 变量。

## 八个板块

| 板块 | 路由 | 一句话 |
| --- | --- | --- |
| HOME | `#/` | 首屏：正在播放（歌词 + 波浪音浪）、最新内容、模块索引 |
| LOGS | `#/logs` | **文章与公告合并**成一条时间线：类型 / 分类 / 标签 / 关键词筛选 |
| MUSIC | `#/music` | 搜索 / 导入网易云曲目，用官方外链播放器试听，站内跟唱歌词 |
| GALLERY | `#/gallery` | 相册（770 张）与随机插画（本地相册 / Pixiv 双数据源） |
| MINES | `#/mine` | 扫雷，三档难度，键盘与触屏都能玩 |
| TOOLS | `#/tools` | 工具台：格式转换、图片压缩、文本处理，全部在浏览器里跑 |
| CONSOLE | `#/admin` | 发布控制台：写文章、公告、管理内容 |
| STATUS | `#/dashboard` | 由插件注册的仪表盘：内容分布、运行状态 |

> 以前 NOTICE 与 LOGS 是两个板块，内容却都是"按时间顺序的发布物"，切来切去很碎；
> 现在合并到 `#/logs`，旧地址（`#/posts`、`#/news`、`#/post/<id>`）会自动跳过去。

## 三条自我约束

> [!NOTE]
> **不打包**：浏览器原生 ES 模块 + hash 路由，`file://` 直接打开也能看到页面（内容会退化成内置示例）。
> **不碰音频流**：网易云只代理元数据与歌词，播放交给官方外链播放器。
> **不做登录**：不收集任何账号凭据；会员曲目会明确提示，并给出可播放的替代版本。

工具台也守着同一条线：文件**不上传**，转换全在浏览器内存里完成，关掉页面就没了。

## 怎么跑起来

```bash
node server.mjs 5173      # 静态文件 + 内容 API + 网易云/Pixiv 代理
# 打开 http://localhost:5173
```

只用静态托管也能跑：所有内容在 `data/*.json`，页面通过 `fetch` 读取；没有服务器时，发布控制台会把内容存进浏览器本地存储并可导出。

## 自检

改完代码跑一遍：

```bash
node tools/verify.mjs        # 178 项：路由 / 交互 / 代理 / 持久化 / 几何 / 动效
node tools/test-markdown.mjs # 33 项：Markdown 与文档示例
node tools/responsive.mjs http://localhost:5173 '#/'
```

自检用真实的 Chromium（CDP）驱动页面，不是 jsdom 模拟——所以它的结论和肉眼看到的一致。
