# 鱼庙的界面规范（endfield 采纳版）

> 来源：[hhikr/endfield-ui-skill](https://github.com/hhikr/endfield-ui-skill)（一个把终末地工业风提炼成规则的 Agent Skill）。
> **只采纳规则，不拷它的代码/资源** ✓ —— 那个仓库只对字体声明了许可（Saira, OFL），代码部分没写明，所以
> `assets/endfield.css` / `fx.js` 一律不用，全部按规则自己写。
>
> 这份文件是"为什么这么做"的记录。改界面之前先读它。

## 一、定位：不换皮，提规整

鱼庙原有的气质不能丢：**纸色底 + 墨黑 + 信号黄 + 等宽标签 + 方角 + 硬阴影**。这套和终末地同源
（浅底黑字、单一亮色、宽体英文标签、切角、极淡纹理），所以这次是**补规矩**，不是换风格。

明确不做 ✗：
- 不引入游戏素材、不做满屏科幻 HUD、不加第二第三种亮色
- 不做全站切角（廉价感来源）—— 只给主按钮和卡片左上角
- 不把信号黄换成那个仓库的 `#FFFA00`（保留鱼庙的 `#FFD400`）

## 二、六维取值（我们的固定选择）

| 维度 | 我们的取值 | 说明 |
|---|---|---|
| 亮色（accent） | **信号黄 `#FFD400`** | 站点身份，不动 |
| 纸色（paper） | **`#EFEDE6`**（暖） | 现有纸色，不动 |
| 切角（cut） | **标准** —— 主按钮 12px、卡片 0（只在左上角给内容卡 1 刀） | 克制 |
| 底纹（ground） | **网格 + 极淡等高线**（等高线只出现在首页/板块头，透明度 ≤ 0.06） | 不铺满 |
| 疏密（density） | **标准** | 现有间距 |
| 动画（motion） | **满**，但尊重 `prefers-reduced-motion` | 见下 |

## 三、部件规则

- **按钮**：主按钮（`btn--signal`）**左下角切一刀**；悬停时亮色从左侧**擦入**（不是整块变色）；
  `:active` 下压 1px。禁用态不加动效。
- **列表 / 表格行**：**每行带编号**（`01` `02`…，等宽，低位灰）；悬停时**左缘色条落下 + 整行右移 2px**。
- **标题（viewhead）**：上面一行**拉宽的英文小字**（`letter-spacing` ≥ 0.2em，全大写），下面粗体中文 ——
  这是现有 `viewhead({title, idx})` 的加强版，不新造部件。
- **背景**：现有网格之外，在页面顶部加一层**极淡等高线**（SVG，`opacity ≤ .06`），不滚动、不抢内容。
- **状态**：正常/警告/危险沿用现有 `--ok/--alert`，不加新色。

## 四、动效规范（最重要的一条：全站统一手感）

三条曲线（放进 `styles/tokens.css`，全站只用这三条）：

```
--ease-snap:  cubic-bezier(.2,.9,.1,1)      /* 迅速到位后稳住：列表、切换、补位 */
--ease-mech:  cubic-bezier(.55,.06,.22,1)   /* 慢起硬停：擦入、面板推入、对话框通电 */
--ease-soft:  cubic-bezier(.4,0,.2,1)       /* 只给颜色/背景变化 */
```

时长表（超过 620ms 的一律不要 ✗）：

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按下 | 100ms | snap |
| 悬停擦入 / 亮边扫过 | 280ms | mech |
| 列表逐行亮起 | 320ms，每行晚 38ms | snap |
| 底部面板推入 / 退出 | 360 / 240ms | mech |
| 对话框通电 / 关上 | 280 / 180ms | mech |
| 提示条（toast） | 擦入 280 → 停 2s → 擦掉 160 | mech |
| 页面入场（通电/字标推入） | 520–620ms，整体 ≤ 1s | mech |
| 乱码后落定（scramble） | 600ms，每个字符晚 ≤ 40ms | linear |

规则：
- **不弹跳、不抖动**（错误用"擦入 + 变色"提示，不 shake）
- 一次页面入场**总时长 ≤ 1 秒**，超出说明编排错了
- 系统开"减少动态效果"（`prefers-reduced-motion: reduce`）时，**全部直接跳到结束态**，只保留颜色变化

## 五、落地顺序与验收

一页一页来，每页都要 `verify.mjs`（212）+ `responsive`（19 宽度，退出码 0）+ 我亲自看截图：

1. **MINES / 扫雷**（部件最全：按钮、列表、面板、状态）← 试点
2. 论坛（列表行编号 + 悬停右移收益最大）
3. 画廊（卡片切角 + 等高线）
4. 音乐台（面板推入）
5. 控制台（表格编号）
6. **首页**（最显眼，最后动）
