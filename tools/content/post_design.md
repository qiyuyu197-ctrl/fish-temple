## 三个词：纸、墨、信号黄

整个站点的颜色都收在 `styles/tokens.css` 里，界面代码不写死任何一个色值。

| 令牌 | 纸色主题 | 作用 |
| --- | --- | --- |
| `--paper` | `#EFEDE6` | 底色（奶油纸） |
| `--paper-2/3` | `#E6E3D9` / `#DCD8CB` | 面板、沉底 |
| `--ink` | `#121316` | 文字与硬边 |
| `--signal` | `#FFD400` | 唯一强调色：当前项、播放中、可操作 |
| `--alert` / `--ok` | `#E2452B` / `#1F7A4D` | 警示 / 通过 |

主题现在有五套：`paper`（日间阅读）、`night`（暗色终端）、`blueprint`（蓝图冷色）、`matcha`（抹茶日间）、`sakura`（樱花日间）。顶栏 ◐ 或键盘 `T` 循环切换，深浅两套语义靠 `<html data-scheme>` 分支，不用给每个主题重写组件。

## 直角、等宽、大写

- **零圆角**：所有面板、按钮、标签、输入框都是 `border-radius: 0`
- **等宽大写做标签**：`PLAYLIST` `SOURCE` `NOW` 这类元信息统一用等宽字体、加宽字距、全大写
- **HUD 角标**：面板四角的细直角（`.hud-corner`），指的是“仪表盘”而不是“卡片”
- **1px 硬边**：面板靠 `--line` / `--line-strong` 两级边框分层，不用阴影和模糊

## 终末地风味层

`styles/ef.css` 是全站共用的一层加法，不改页面结构，只统一四件事：

- **字体**：Saira 自托管，英文标签宽 112% / 125%，中文落回系统黑体
- **切角 = 可点击**：按钮、筛选块、工具按钮切右下角；展示用的封面与面板保持直角
- **强调色只做填充**：黄块编号、黄底状态、进度填充；“当前位置”的线在浅色主题用墨色
- **页面级随机应变**：首页大胆、阅读页安静、控制台密集，但上面三条不变

## 动效只做有信息量的

不做装饰性动画，只做“状态变了”的提示，并且都给 `prefers-reduced-motion` 和站内「减少动效」让路：

| 动效 | 说明什么 |
| --- | --- |
| 歌词换句翻转 | 这一句是新的一句 |
| 扫雷格子级联落下 | 这一片是刚被展开的 |
| 踩雷震屏 | 结束，且是你踩的 |
| 底栏与首页的波浪音浪 | 有没有在响、响到哪一段 |
| 首页横幅视差 | 页面在滚动，幅度很小 |

波浪音浪有一套数据源（`miniaudio.js` 的 `waveLevels`）：自托管音频走真频谱，跨域的网易云曲目走合成音浪，**底栏和首页共用同一套幅度**，所以两处波动是一致的。

## 响应式

1920 到 360 不出现横向滚动。1300 以下把顶栏导航收进抽屉，避免十个板块挤在登录头像和时钟旁边；900 以下网格降列，600 以下把工具台与游戏的分段按钮改成可横滑。导航项的序号在 1680 以下先隐藏，保证标签不被挤压。

## 品牌标记

标记的源文件是一张插画，一条命令生成四个尺寸并做墨色衬底：

```bash
python tools/make-brand.py
# mark-512.png · mark-64.png · favicon-32.png · apple-touch-icon.png
```

两个踩过的坑写在注释里：一是裁切框要留出头顶到肩膀（只露个头会很怪），二是**favicon 缓存**——服务器换了图标浏览器也未必更新，必须改 URL（`favicon-32.png?v=N`），因为 Chromium 的图标存在独立的 Favicons 库里。
